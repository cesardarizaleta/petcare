# Vue 3 SDK Template ⚡️

Una plantilla base configurada y lista para producción, diseñada para que empieces a programar tu aplicación inmediatamente sin preocuparte por la configuración inicial.

## 🚀 Quick Start (Empezar rápido)

La forma más rápida de arrancar:

```bash
# 1. Instalar dependencias y levantar el servidor de desarrollo al instante
npm run start
```

_(Puedes presionar `Ctrl + C` en la terminal para detener el servidor)_

### 🛠️ ¿Qué incluye esta plantilla?

- **[Vue 3](https://vuejs.org/)** + **[Vite](https://vitejs.dev/)**: Carga ultrarrápida y Hot Module Replacement (HMR).
- **[Vue Router](https://router.vuejs.org/)**: Sistema de rutas ya configurado (`src/router/index.js`).
- **[Pinia](https://pinia.vuejs.org/)**: Manejo de estado global fácil de usar (`src/stores/`).
- **Estructura escalable**: Componentes reutilizables, UI base, y división clara por vistas.

---

## 💻 ¿Cómo empiezo a programar mi propia app?

1. **Modifica el menú y las páginas**: Entra a `src/App.vue` o a las vistas en `src/views/` y empieza a cambiar el HTML/Vue.
2. **Crea un componente**: Añade tu código en `src/components/`, ej: `MiComponente.vue`.
3. **Cambia los datos**: Ve a `src/data/mockData.js` o usa `src/stores/` para agregar el estado de tu aplicación.

```bash
# Otros comandos útiles:

npm run dev    # Levanta el servidor si ya instalaste las dependencias
npm run build  # Construye la app lista para producción
npm run format # Formatea todo tu código usando Prettier
```
